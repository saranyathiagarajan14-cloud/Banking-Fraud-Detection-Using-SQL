# Banking-Fraud-Detection-Using-SQL

## 📌 Project Overview
This project focuses on analyzing banking transactions using SQL to identify fraudulent transactions and understand potential fraud patterns. It uses transaction details, payment channels, authentication methods, device risk scores, login activity, and suspicious IP indicators to explore fraud-related trends.

## 🎯 Objectives

Identify fraudulent and legitimate transactions.

Calculate fraud rates and amounts.

Analyze fraud by payment channel and authentication type.

Investigate suspicious IPs, device risks, and login activity.

Compare international and domestic fraud patterns.

## 🛠️ Tools & Technologies

MySQL Workbench

## 📊 Key Results

- Total Transactions: 10,000
- Fraudulent Transactions: 1,251
- Legitimate Transactions: 8,749
- Fraud Rate: 12.51%
- Total Transaction Amount: 15,657,404.21

## 📁 Project Files Include

- SQL Database and Table Creation
- Data Loading Queries
- Data Filtering and Transformation
- Aggregate Functions and Grouped Analysis
- Joins and Subqueries
- Window Functions
- Fraud Analysis Queries

## 💡 Outcome

The project provides insights into banking transaction fraud patterns using SQL. It helps analyze fraudulent transactions, payment channels, authentication methods, suspicious IP addresses, and device risk indicators to support fraud monitoring and risk assessment.
